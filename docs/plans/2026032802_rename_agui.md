# Rename AG-UI event types to protocol-agnostic names

## Context

The shared event model (`AGUIEvent`, `AGUITimestampedEvent`, `convertToAGUIEvent`) is used by the runner, recorder, and `ProtocolClient` interface — layers that must be protocol-agnostic. The "AGUI" prefix on these shared types is misleading since they represent a generic event vocabulary, not AG-UI-specific constructs. This rename clears the path for future protocol clients to use the same event model without confusion.

## Renames

| Current | New |
|---------|-----|
| `AGUIEvent` | `ProtocolEvent` |
| `AGUIEventType` | `ProtocolEventType` |
| `AGUITimestampedEvent` | `TimestampedProtocolEvent` |
| `convertToAGUIEvent()` | `toProtocolEvent()` |

## Not renamed (correctly scoped to AG-UI protocol)

- `AGUIClient`, `AGUIClientOptions` (in `agui.ts`)
- `AGUIWSSClient`, `AGUIWSSClientOptions` (in `aguiwss.ts`)
- `AGUITarget`, `AGUIWSSTarget` (in `config.ts`)
- Local variables like `aguiEvent` inside client files
- Log prefixes like `[AG-UI]`, `[AGUIWSS]`

## Files to modify

### 1. `src/client/events.ts` — definitions

- `AGUIEvent` → `ProtocolEvent` (type alias)
- `AGUIEventType` → `ProtocolEventType` (type alias)
- `AGUITimestampedEvent` → `TimestampedProtocolEvent` (type alias)
- `TimestampedEvent` — update reference from `AGUIEvent` to `ProtocolEvent`
- `convertToAGUIEvent()` → `toProtocolEvent()` (function name + JSDoc + return type)

### 2. `src/client/types.ts` — ProtocolClient interface

- Import `TimestampedProtocolEvent` instead of `AGUITimestampedEvent`
- `message()` return type
- `resume()` return type

### 3. `src/client/agui.ts` — AG-UI client internals

- Import `toProtocolEvent` instead of `convertToAGUIEvent`
- Import `TimestampedProtocolEvent` instead of `AGUITimestampedEvent`
- Return types on `message`, `resume`, `executeRequest`
- Local array type `events: TimestampedProtocolEvent[]`
- Call site `toProtocolEvent(event)`

### 4. `src/client/aguiwss.ts` — WSS client internals

- Import `toProtocolEvent` instead of `convertToAGUIEvent`
- Import `TimestampedProtocolEvent` instead of `AGUITimestampedEvent`
- Return type on `message`
- Local array type `eventQueue: TimestampedProtocolEvent[]`
- Call site `toProtocolEvent(event)`

### 5. `src/runner/step.ts` — runner layer

- Import `TimestampedProtocolEvent` instead of `AGUITimestampedEvent`
- `formatEventDetail` param type
- `handleEvent` param type

### 6. `src/client/index.ts` — re-exports

- No changes needed. It re-exports `* from "./events.js"` which covers the renamed types automatically.

### 7. `src/recording/recorder.ts` — recording layer

- Verify imports reference `TimestampedEvent` (unchanged) not `AGUITimestampedEvent` directly.
